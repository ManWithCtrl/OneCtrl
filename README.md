# 控制校正验算器OneCtrl

一个把「控制理论作业/考试」里手算出来的每一步都验证一遍的本地小工具：输入原开环传递函数 `G₀(s)` 和校正环节 `Gc(s)`，它会把 Bode、阶跃、根轨迹、Nyquist、稳定性判据、非线性描述函数全部算给你看，并与浏览器里的实时预览互相印证。

纯本地运行，数据不出本机；Python 负责精确数值（numpy/sympy/matplotlib），实时拖动的预览在浏览器里用 JS 现算。

## 快速开始

```bash
pip install -r requirements.txt
python ctrl_web.py --no-open        # 默认 http://127.0.0.1:8000
```

命令行参数：`-p/--port`（默认 8000）、`--host`（默认 0.0.0.0）、`--no-open`（不自动开浏览器）。

表达式支持普通写法（`s^2`、`0.5s`、`2s+1`、`1/(s(s+1))`）和 LaTeX（`\frac{a}{b}`）；离散系统把 `T` 填上即可，也可直接写 `z` 的 `D(z)`（自动双线性变换）。

## 功能

**分析页**

- 指标卡：截止频率 `ω_c`、相角裕度 `γ`、超调量 `σ`、调节时间 `t_s`、主导阻尼比 `ζ`、稳态误差 `e_ss`
- 公式回显（MathML）：`G(s)`、`L(s)`、`Φ(s)`、特征方程，零极点与型别
- 实时联动：拖动增益 `K`，Bode 与闭环阶跃曲线同步变形
- 正弦稳态 `y_ss(t)=A|G(jω)|sin(ωt+∠G(jω))` 与主导极点二阶近似
- 示波器（`r(t)`/`c(t)`/`e(t)`，鼠标拖动读数）
- 相平面：闭环主导二阶相图，点击可加轨迹；闭环特征式退化时自动退回画开环相图
- 根轨迹：`K = 0.01…1000` 牛顿延拓追踪 + 自适应细分，拖 `K` 或空白平移缩放
- Nyquist 交互：拖动平移、滚轮缩放，超长坐标按画布裁剪
- 校正/曲线/稳定性：Routh 表、Nyquist 判据、Bode 上下限、闭环极点分布

**非线性**：继电器、滞环继电器、死区、饱和、间隙，时域仿真 + 描述函数交点（滞环为**复值**描述函数，`−1/N(A)` 是 `Im = −πa/(4M)` 的水平射线，交点给出自振幅值/频率/周期，并用自由响应判定稳定性）

**稳定性**：Routh（含零行/临界）、Nyquist 包围数、Bode 稳定裕度、描述函数自振点

**工具**：校正设计、离散化（Tustin）验算等
